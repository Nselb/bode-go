# BodeGO

![CI](https://github.com/Nselb/bode-go/actions/workflows/CI/badge.svg)

## Description

Inventory management solution for small business.

## Setup

1. Install dependencies

```bash
pnpm install
```

2. Setup env variables

```bash
cp .env.example .env
```

And change with your own values.

3. Setup database

```bash
docker compose up -d
```

4. Run project

```bash
pnpm dev
```
